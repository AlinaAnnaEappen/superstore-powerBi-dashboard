# 📊 Power BI Superstore Sales & Profit Dashboard

## 🎯 Objective

The objective of this project was to analyze and visualize business data using Power BI to derive meaningful insights from the Sample Superstore dataset. The focus was on building an interactive dashboard, identifying key performance metrics, and presenting insights in a structured and easy-to-understand format.

---

## 📂 Dataset Information

**Dataset:** Sample Superstore Dataset  

- Rows: ~9,994  
- Columns: 13–16 (varies by import)

### Key Columns Used:
- Order ID  
- Order Date  
- Ship Date  
- Segment  
- Region  
- Category  
- Sub-Category  
- Product Name  
- Sales  
- Profit  

---

## 🧹 Data Preparation

- Verified dataset structure and data types  
- Ensured correct aggregation of Sales and Profit  
- Checked for missing or inconsistent values  
- Standardized fields for visualization in Power BI  

---

## 📊 Visualizations Created

The dashboard includes the following visualizations:

- Sales by Category  
- Profit by Category  
- Sales by Region  
- Profit by Region  
- Top 10 Products by Sales  

### KPI Cards:
- Total Sales  
- Total Profit  
- Profit Margin  

---

## 📈 Key Insights

- Technology category has the highest sales and profit, indicating strong demand.  
- Furniture category shows the lowest profit, suggesting cost or pricing inefficiencies.  
- West region performs the best in both sales and profit.  
- Central region shows comparatively lower performance.  
- Canon imageClass 2200 Advanced Copier is the top-selling product.
